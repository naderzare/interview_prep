# Topic practice: 0 → hero

Work down one file at a time, or jump to a topic you keep forgetting. Each file has **10 unsolved questions**, roughly ordered from simple to difficult. Every question has an example and a function to complete. The example is a check of behavior, not a full test suite.

Before coding, say out loud: **What clue points to this technique? What fact stays true while my code runs? What are the time and space costs?** Then solve without opening the matching review card. Use the card afterward to check the idea and variation.

From this directory, run `python 00-hashmap.py 1` to check Question 1, or change the number to check another question. Without a number, the file checks Question 1. A few problems intentionally combine techniques; explain which part each technique handles.
